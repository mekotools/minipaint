# mekotools/minipaint

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: Der Inhalt ist das fertige Container-Abbild, das hier veröffentlicht
wird, damit es auf gemieteten GPU-Instanzen (vast.ai) **ohne Anmeldung**
gezogen werden kann.

- Werkzeug: miniPaint (Bildbearbeitung im Browser, viliusle)
- Bezug: `docker pull ghcr.io/mekotools/minipaint:latest`
- Zweck: Medienkompetenz und Medienbildung für Lehrkräfte (Projekt MekoTools)
- Bauvorschrift: `tilllt/mekotools/mekotools-minipaint-a79733eb` (interne GitLab-Instanz),
  Quelltext-Stand `viliusle/miniPaint` @ `a79733eb` — Lizenz MIT

Die Quelldaten des Abbilds liegen im internen Bau-Repo; hier steht nur das
veröffentlichte Ergebnis samt Zuliefer-Workflow.
